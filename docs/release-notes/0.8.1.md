- Added a new voice visual, Edge Glow + Draft. The edge beam on the silhouette with your last words centered inside it, so you can read what was heard without the shape growing a text band. Pick it in **Settings → Appearance**.
- The live draft now streams while you are still speaking rather than appearing at pauses, and a correction rewrites in place instead of sliding.
- Fixed "Listening (latched)" staying on screen after you stopped speaking, under the shaping caption. The shaping phase cleared it, but a model download finishing in that moment asked for it back. Nothing writes it once a session stops listening now.
- Fixed a status message keeping the previous session's shaping caption and draft behind it.
- Homebrew installs in one command again: `brew install --cask tornikegomareli/talkify/talkify`. The full name adds the tap and trusts that one cask, so the separate `brew tap` and `brew trust` steps are gone.
